# Avito to Telegram Notifier

Асинхронный сервис на базе Python (FastAPI и HTTPX) для пересылки входящих сообщений из чатов Авито в Telegram в режиме реального времени.

Сервис принимает события через официальный Webhook Авито, фильтрует исходящие сообщения владельца и мгновенно отправляет уведомления с текстом сообщения и прямой ссылкой на диалог.

---

## Возможности

- Мгновенная доставка уведомлений через официальный Webhook API Авито.
- Автоматическая фильтрация собственных исходящих сообщений.
- Формирование прямой ссылки на чат в веб-версии Авито.
- Экранирование спецсимволов HTML для предотвращения ошибок парсинга в Telegram.
- Автоматическая авторизация, получение внутреннего User ID и регистрация вебхука при старте сервиса.

---

## Требования к аккаунту Авито

Для получения текста сообщений через Messenger API профиль на Авито должен иметь подписку с доступом к API мессенджера (тарифы линейки «Авито Pro» с подключенным доступом к сообщениям). 

На базовых частных аккаунтах без расширенного тарифа Авито ограничивает отправку вебхуков и заменяет текст сообщений системной заглушкой.

---

## Требования к окружению

- Python 3.10 или выше
- Установленный менеджер пакетов pip
- Доступный публичный HTTPS-адрес для приема вебхуков (статический IP, домен с SSL или утилиты туннелирования cloudflared / localtunnel для локальных тестов)

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/username/avito-telegram-notifier.git
cd avito-telegram-notifier
```
2. Создайте и активируйте виртуальное окружение:
```
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```
3.  Установите зависимости:
```
pip install fastapi uvicorn httpx python-dotenv
```
## Настройка конфигурации

Создайте файл .env в корневой директории проекта со следующим содержимым:
```
AVITO_CLIENT_ID=your_avito_client_id<br>
AVITO_CLIENT_SECRET=your_avito_client_secret<br>
TG_BOT_TOKEN=your_telegram_bot_token<br>
TG_CHAT_ID=your_telegram_chat_id<br>
WEBHOOK_URL=https://your-domain.com/webhook<br>
```
## Инструкция по получению параметров

1.  AVITO_CLIENT_ID и AVITO_CLIENT_SECRET:

      - Авторизуйтесь в личном кабинете на сайте developers.avito.ru.
      - Перейдите в раздел получения API-ключей.
      - Создайте ключи с правами доступа к модулю сообщений (messenger:read,
        messenger:write).

2.  TG_BOT_TOKEN:

      - Откройте Telegram и перейдите к боту @BotFather.
      - Выполните команду /newbot, укажите имя и username бота.
      - Скопируйте полученный HTTP API токен.

3.  TG_CHAT_ID:

      - Узнайте свой цифровой идентификатор в Telegram с помощью бота
        @userinfobot или @getmyid_bot.
      - Обязательно откройте диалог со своим созданным ботом и отправьте команду
        /start. Без этого бот не сможет отправлять вам сообщения.

4.  WEBHOOK_URL:

      - Укажите публичный HTTPS-адрес вашего сервера, завершающийся путем
        /webhook.
      - Пример: https://subdomain.domain.com/webhook.
      - Внимание: использование протокола HTTP не поддерживается API Авито.

## Запуск сервиса

Запустите основной файл приложения:
```
python main.py
```
При успешной инициализации в консоли отобразятся следующие этапы:
```
1.  Авторизация в OAuth2 сервисе Авито.
2.  Получение локального User ID аккаунта.
3.  Регистрация указанного адреса WEBHOOK_URL в API Авито.
4.  Запуск веб-сервера Uvicorn на порту 8000.
```

# Безопасность

  - Никогда не передавайте и не загружайте файл .env в публичные репозитории.
  - Убедитесь, что файл .gitignore содержит запись .env.
  - При развертывании в production-окружении рекомендуется использовать Nginx в
    качестве reverse-proxy с корректной настройкой SSL-сертификатов (Let's
    Encrypt).
